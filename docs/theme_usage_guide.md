# 资源门户 — 模板使用说明

## 1. 模板概览 (Theme Overview)

### 模板名称

**资源门户**

（配置键：`theme_info.theme_label`，见 `locales/zh-CN.schema.json`。）

### 模板描述

专业的资源管理门户模板，专为数字资产和媒体资源管理而设计。支持多级栏目分类导航、标签分类、多条件查询筛选等功能，具备完善的权限管理体系和资源安全保护。

从项目实现上看，本主题在 **CMS（`theme_scope: cms`）** 场景下提供首页聚合、栏目体系与单资源详情页：首页（`templates/index.liquid`）以列表展示栏目与资源流，并支持配置资源详情是在当前页以弹层打开还是跳转独立详情页；资源栏目页（`templates/channel.liquid`）作为分类目录（实际渲染为带参数重定向至首页的栏目入口）；资源页（`templates/page.liquid`）绑定 DAM 资源、标签与富文本描述，适合作为可检索、可下载的数字资产详情。技术侧采用 Stimulus、Alpine.js、Turbo、Tailwind CSS 4 与 DaisyUI，便于在保持统一视觉的同时扩展交互。

### 适用场景

- **企业/团队资源中心**：集中展示产品资料、设计素材、媒体文件与文档，按栏目与标签组织。
- **数字资产（DAM）对外门户**：需要资源选择器、标签、描述与下载/预览能力，并关注链接有效期与访问控制时。
- **内部资料库或对外下载站**：配合权限、防盗链与下载有效期等能力，做可控分发。

结合模板类型：**首页**负责总览与筛选体验；**资源栏目页**用于分类目录（并可嵌套子栏目与资源页）；**资源**页承载单个文件/资产及说明，适合与检索、标签体系联动。

### 主要特性

- **主题信息**：支持中文简体与 English；可配置缩略图与预览图；内置「资源下载」埋点事件定义；提供默认 / 现代 / 优雅三套推荐配色变量。
- **通用设置**：Logo 图片、公司名称、备案/版权信息。
- **自定义 HTML**：可在 `<head>`、顶栏菜单区、页脚整体替换区、页脚内菜单区插入 HTML（支持有限 Tailwind），便于统计、客服、外链导航与 SEO。
- **资源设置**：资源下载链接有效期（秒，0 为永不过期；预览图有效期说明见配置项）；批量上传等能力使用的 API 地址（默认 `https://open.baklib.com`）。
- **首页模板**：列表展示所有栏目；可设置「资源详细页打开方式」——**页面内打开**（Modal）或 **详情页面打开**。
- **资源栏目页模板**：栏目名称、栏目描述；支持子模板为资源页与嵌套栏目；缩略图展示用 `index-1.png` 等主题图。
- **资源模板**：资源名称、资源选择（DAM）、资源标签、可搜索的富文本资源描述；支持批量创建入口（`batch_create_url`）等扩展。

### 附录：配置项中文名称（与 `locales/zh-CN.schema.json` 一致）

**通用设置**

| 配置项 | 说明（摘录） |
|--------|----------------|
| Logo 图片 | 若设置了 logo，则页头显示 logo，否则显示网站图标 + 站点名称 |
| 公司名称 | 显示在页面底部页脚位置 |
| 备案/版权信息 | 页脚展示用 |

**自定义 HTML 代码**

| 配置项 | 说明（摘录） |
|--------|----------------|
| 自定义 `<head></head>` 标签中的 HTML | 可放统计、客服机器人等 |
| 顶部导航区域插入 HTML 代码 | 如其他站点导航链接 |
| 页脚区域插入 HTML 代码 | 将完全替换默认页脚；若需保留默认页脚请用下方项 |
| 底部区域插入 HTML 代码（footer 内） | 外链、友情链接、SEO 等 |

**资源设置**（`settings_schema.json` 内联中文标签）

| 配置项 | 说明（摘录） |
|--------|----------------|
| 资源下载链接有效期 | 单位：秒；0 为永不过期；预览图有效期固定为 7200 秒 |
| API 地址 | 批量上传等功能使用的 API 地址 |

**模板：首页**

| 配置项 | 选项/说明 |
|--------|------------|
| 资源详细页打开方式 | 页面内打开（Modal） / 详情页面打开 |

**模板：资源栏目页**

| 配置项 | 说明 |
|--------|------|
| 栏目名称 | — |
| 描述 | 栏目描述 |

**模板：资源**

| 配置项 | 说明 |
|--------|------|
| 资源名称 | — |
| 资源选择 | DAM 选择器 |
| 资源标签 | 可多选 |
| 资源描述 | 富文本，可参与搜索 |
